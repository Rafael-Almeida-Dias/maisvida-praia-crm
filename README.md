# CRM & Controle de Alunos — MaisVida Praia
MVP de gestão de alunos, horários de treino e radar de aniversariantes desenvolvido em Python e Streamlit, integrado ao Google Forms/Sheets (ODS 8.3).

## Como executar localmente
1. Instale as dependências: `pip install -r requirements.txt`
2. Execute a aplicação: `streamlit run app.py`
